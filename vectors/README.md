# Test vectors

## `custody-v1.json`

Generated by `code/ts/scripts/gen-vectors.mjs` (after `pnpm build` in `code/ts`) and checked by the TypeScript, Python, Go, Rust and Java test suites. Transactions are hand-encoded and signed with QoreSign; expected results are written from the inputs, not produced by the decoder under test.

Every key is derived from the public BIP-39 test mnemonic (`abandon ... about`). The signed transactions use account numbers that do not belong to these keys on any network, so they cannot be broadcast. Never send funds to these accounts.

| Field | Contents |
|---|---|
| `addresses.valid`, `addresses.invalid` | inputs to `validateAddress` with options, and the expected result or error code (one case per code) |
| `transactions` | a hybrid-signed `MsgDelegate` from a `secp256k1` account and a hybrid-signed `MsgOpenEVMWindow` from an eth-native account: bytes, keys, the expected `decodeTx` output, and `verifyCases` (registered key, classical only, wrong ML-DSA-87 key, wrong account number, wrong chain id, wrong secp256k1 key) |
| `messages` | single messages (staking, staking tier, window with targets, multi-send, an unknown type) and their expected decoding |
| `malformed` | transactions `decodeTx` must refuse, with the error code |
| `depositQueries`, `depositQueryErrors` | options of `buildDepositQuery` and the exact expected path, or the error code |
| `deposits` | a `tx_response`, an address and the expected `extractDeposits` entries |
| `moduleAccounts` | addresses of the fee collector, EVM and distribution module accounts (identical on both networks) |

All byte strings are lowercase hex. ML-DSA-87 signatures are deterministic (FIPS 204, `rnd` = 32 zero bytes); secp256k1 signatures use RFC 6979 and low-S.

## QoreSign vectors, by reference

The hybrid-signing vectors of QoreSign are not copied here. `scripts/fetch-qoresign-vectors.sh` downloads them from the tagged release and checks the hash recorded in `custody-v1.json` (`qoresignVectors`):

- URL: <https://raw.githubusercontent.com/qorechain/qoresign/v0.1.0/vectors/qoresign-v1.json>
- SHA-256: `bf920288d234204bb77c51b59aec0b3a6c9ce5735cef247a18629b4912186f7c`

When the file is present, every language also verifies its `hybridTx` cases (sign-bytes v2 and v1) with `verifyTx`; otherwise that check is skipped.
